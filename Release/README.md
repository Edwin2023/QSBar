**QSBar** 是一款高效的表格辅助插件，提供一套统一的代码同时兼容 **Microsoft Excel** (包括 Excel 2021) 和 **WPS 表格**。本插件旨在通过集成批量处理、格式排版、一键导出等功能，大幅提升您的办公效率。

***

## 🚀 核心功能 (QS工具箱)

安装插件后，您的 Excel 或 WPS 的顶部菜单栏将出现 **“QS工具箱”** 选项卡，主要包含以下功能模块：

- **格式/排版**：支持数据批量处理、数值化、文本化强制转换，以及一键锁定/解锁公式。
- **批量处理与导出**：
  - 一键根据内容设置分级显示及分级样式。
  - 支持快速导出当前工作表、标准报表（删除隐藏行列）、内部报表等（自动转为数值形式）。
- **分级/筛选与目录生成**：
  - 快速合并多个工作表。
  - 一键生成当前工作簿的**表目录**或选择文件生成**文件目录**。
- **对象与图片处理**：一键选中可见单元格（Ctrl+5）、全选图片，支持图片 1倍/2倍/4倍 快速缩放。
- **工作表高级操作**：
  - 全表公式一键数值化（粘死）、强制刷新公式。
  - 一键取消隐藏所有工作表、删除所有空行。
  - 清理外部链接、删除超链接，断开所有外部工作簿引用。
- **计算模式切换**：一键在“自动计算”与“手动计算”之间切换（快捷键 F10），避免卡顿。
- **在线更新**：内置版本检查与在线更新功能，点击“重启更新”即可轻松升级。

## 🛠️ 安装说明

📥 **[👉 点击此处下载最新版安装包 (ZIP压缩格式)](https://gitee.com/kevin137/QSBar-release/raw/master/QSBar_Setup.zip)**

2. 双击运行解压出来的安装程序（`.exe` 文件），按照提示完成安装。
3. 安装完成后，重启 Microsoft Excel 或 WPS 表格。
4. 在顶部菜单栏即可看到 **“QS工具箱”**。

## 💡 常见问题 (FAQ)

- **安装后插件没有显示在菜单栏怎么办？**
  通常是因为 Excel 将插件误加入了“禁用项”。
  *解决办法*：进入 Excel 的 `文件` -> `选项` -> `加载项` -> 底部管理选择 `禁用项目` -> 点击 `转到`，找到 QSBar 并启用即可。
- **插件支持哪些 Office 版本？**
  支持 Microsoft Excel (推荐 2013 及以上版本，包括 Excel 2021) 以及主流版本的 WPS 表格。
- **部分功能报错或无响应？**
  请确保您的电脑已安装 **.NET Framework 4.8**。
