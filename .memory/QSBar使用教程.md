# QSBar 使用教程 -- 从小白到熟练

---

## 一、QSBar 是什么？

QSBar 是一款 **Excel / WPS 表格插件**，安装后会在菜单栏添加一个"**QS工具箱**"选项卡，提供批量处理、格式排版、一键导出、分级显示等实用功能，帮你从繁琐的表格操作中解放出来。

简单说：**装了它，你的 Excel 会多出一排按钮，点一下就能完成以前要操作好几分钟的事情。**

## 二、安装前的准备

### 你的电脑需要满足以下条件：

| 条件 | 说明 |
|------|------|
| **操作系统** | Windows 7 及以上（Win10/Win11 都可以） |
| **Office 版本** | Microsoft Excel 2013 及以上（含 Excel 2021），或 WPS 表格 |
| **运行环境** | .NET Framework 4.8（一般 Win10 及以上系统自带） |

> **怎么确认有没有 .NET Framework 4.8？**
>
> 打开"控制面板" → "程序和功能" → 左侧点"启用或关闭 Windows 功能"，看看列表里有没有 ".NET Framework 4.8"。如果没有，去微软官网搜索下载安装即可。

## 三、下载与安装（一步一步来）

### 第 1 步：下载安装包

点击下方链接下载最新版安装包：

**[点击下载 QSBar 最新版](https://gitee.com/kevin137/QSBar-release/raw/master/QSBar_Setup_v1.0.1.13.zip)**

下载后你会得到一个 `.zip` 压缩文件。

### 第 2 步：解压压缩包

右键点击下载好的 `.zip` 文件，选择"**全部解压缩**"，然后选一个你方便找到的位置（比如桌面），点"提取"。

![解压示意图](../Installinfo/logo_horizontal.png)

> **注意**：不要直接在压缩包里双击运行，一定要先解压出来！

### 第 3 步：运行安装程序

进入解压出来的文件夹，找到 `.exe` 安装程序（文件名类似 `QSBar_Setup_v1.0.1.13.exe`），**双击运行**。

安装过程很简单，一路点"下一步"即可，不需要改动任何设置。

### 第 4 步：重启 Office

安装完成后，**关闭所有已打开的 Excel 或 WPS 窗口**，然后重新打开 Excel 或 WPS。

### 第 5 步：确认安装成功

打开 Excel 或 WPS 后，看顶部菜单栏，如果出现了 "**QS工具箱**" 选项卡，就说明安装成功了！

## 四、功能介绍与使用方法

QS工具箱里的所有功能都按分组排列在菜单栏上，下面逐一介绍每个按钮是干什么的、什么时候用。

---

### 4.1 格式/排版

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **数值化** | 把公式结果变成固定数值 | 算完了不想让别人看到公式，或者要发给客户 |
| **文本化** | 把单元格内容强制转成文本格式 | 数字前面要加零、身份证号显示不全 |
| **锁定公式** | 保护所有带公式的单元格 | 发出去的表不想让人改公式 |
| **解锁公式** | 取消公式保护 | 需要修改公式的时候 |

---

### 4.2 批量处理与导出

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **分级样式** | 根据内容层级自动设置分级颜色和格式 | 做报价清单、BOQ 清单时快速分成 L1/L2/L3 样式 |
| **导出当前表** | 把当前工作表单独导出为新文件 | 只需要发其中一个 sheet 给别人 |
| **导出标准报表** | 导出并自动删除隐藏行列 | 给领导看的数据要隐藏一些内部信息 |
| **导出内部报表** | 导出为数值形式 | 导出数据给其他人做分析用 |

---

### 4.3 分级/筛选与目录

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **合并工作表** | 把多个 sheet 的内容合到一个 | 年度汇总，12 个月的数据合成一张表 |
| **生成表目录** | 给当前工作簿的所有 sheet 做一个目录页 | 一个文件几十个 sheet，翻来翻去找不到 |
| **生成文件目录** | 选一个文件夹，生成里面所有文件的清单 | 管理一堆 Excel 文件 |

---

### 4.4 对象与图片

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **选中可见单元格** | 只选你能看到的单元格（快捷键 Ctrl+5） | 隐藏了一些行列后，只想复制看得到的部分 |
| **全选图片** | 一键选中表格里所有图片 | 统一调整所有图片的大小 |
| **图片缩放 1x/2x/4x** | 快速缩放选中的图片 | 表格里的图片太大或太小 |

---

### 4.5 工作表高级操作

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **公式粘死** | 全表公式一次性变成数值 | 报表定稿了，所有计算都确认无误 |
| **刷新公式** | 强制重新计算所有公式 | 改了一些数据但结果没自动更新 |
| **取消隐藏** | 一键取消所有隐藏的工作表 | 收到别人的文件，不知道藏了多少东西 |
| **删除空行** | 一键删掉所有空白行 | 整理从系统导出的乱七八糟的数据 |
| **清理链接** | 断开所有外部工作簿引用 | 打开文件老是弹"是否更新链接" |
| **删除超链接** | 去表格中所有的超链接 | 复制粘贴过来的数据带了一堆蓝色链接 |

---

### 4.6 其他实用功能

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| **自动/手动计算** | 在自动计算和手动计算间切换（快捷键 F10） | 表格太大，每改一个数就卡半天，切到手动计算就顺畅了 |
| **重启更新** | 检查并在线更新插件 | 发现 bug 或者有新功能发布时 |

## 五、常见问题解决

### Q1：安装后菜单栏没有"QS工具箱"？

这是最常见的问题 -- Excel 把插件当成了"禁用项"。解决方法：

1. 打开 Excel，点左上角"**文件**"
2. 点左下角"**选项**"
3. 在弹出窗口左边选"**加载项**"
4. 在窗口底部的"管理"下拉框里，选"**禁用项目**"，点"**转到**"
5. 如果列表里有 QSBar，选中它，点"**启用**"
6. 关闭 Excel 重新打开

### Q2：点击按钮没反应或报错？

先确认电脑装了 **.NET Framework 4.8**（检查方法见第二章）。如果确认装了还是不行，卸载后重新安装一次。

### Q3：WPS 能用吗？

支持。安装流程和 Excel 完全一样，效果见上面的 WPS 界面截图。

### Q4：怎么更新到最新版？

打开 Excel/WPS，在 QS工具箱菜单栏找到"**重启更新**"按钮，点击即可自动检查更新。

也可以去下载页面手动下载最新安装包，覆盖安装即可（不用先卸载旧版）。

### Q5：安装需要管理员权限吗？

不需要。插件注册在当前用户下，不需要管理员密码。

## 七、小技巧合集

1. **Ctrl+5**：这是最常用的快捷键之一，只选中看得见的单元格，复制时不会把隐藏的数据也带出来。
2. **F10**：表格太大操作卡顿？按 F10 切到手动计算，改完数据再按一次切回来自动计算。
3. **先分级再导出**：如果你的数据有层级关系，先用"分级样式"按钮设好颜色，再用"导出标准报表"，导出来的文件就自带美观的分层样式。
4. **合并前备份**：使用"合并工作表"功能前，建议先保存一下文件，万一合并不满意可以撤销。
